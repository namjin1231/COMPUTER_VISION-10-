# AI 작업 지침 — 낙상 감지 전이학습 (train/)

이 폴더에서 일하는 AI 코딩 도구(Claude Code, Codex 등)가 먼저 읽는 지침이다. 사람용 설명서는 `00_README_학습꾸러미.md`이니 끝까지 읽고 시작한다. 최종 모델의 근거와 결과는 `참고_인수인계_최종모델.md`에 있다.

## 목표
사용자가 준비한 새 데이터셋으로 최종 모델 R-b(`runs/Rb_r2_sel/tcnte_seed0~2/best.pt`)에서 이어서 학습(전이학습)하고, 결과를 보고한다.

## 파이프라인 (한 줄 요약)
영상 → 15fps → YOLO26n-pose + ByteTrack 관절 17개 (03) → 영상마다 주인공 1명 선택 + 프레임별 정답 (04) → 특징 55개, 영상별 시퀀스 (05) → 최근 30프레임(2초)을 TCNTE에 넣어 매 프레임 0 정상 / 1 넘어지는 중 / 2 쓰러져 있음 (06) → 평가와 2단계 판정 (07, demo_video).

## 바꾸면 안 되는 것
R-b 가중치와 맞물려 있다. 바꾸면 전이학습이 아니라 다른 모델이 된다.
- 15fps, 30프레임 창, 관절 17개(COCO 순서), 특징 55개(`features.py`), 모델 구조(`models.py`의 TCNTE), 미래 프레임을 보지 않는 구조
- 06이 학습 전에 '미래 차단 테스트'를 돌린다. 실패하면 학습을 멈춘다.
- 정답 체계: 0 정상, 1 넘어지는 중, 2 쓰러져 있음, 6 그냥 누워 있음(학습·채점 제외), 구간 밖 시간은 제외
  - 변환은 `common.to3`가 한다. 다른 라벨 변환 함수를 새로 만들지 않는다.
- 관절 추출 모델은 `yolo26n-pose.pt`, 입력 640이다. R-b가 이 관절로 학습됐다.
- 고칠 일이 생기면 기존 동작은 그대로 두고 옵션으로 추가한다. 무엇을 왜 고쳤는지 사용자에게 알린다.

## 데이터 준비에서 확인할 것
- 정답표 두 개 `labels/videos_<이름>.csv`, `labels/segments_<이름>.csv`를 만든다.
  - 형식은 `labels/*_예시.csv`와 README 2절을 따른다.
  - 사용자 데이터의 원래 라벨을 0/1/2/6으로 바꾸는 규칙은 **사용자에게 확인받고** 적용한다. 특히 앉아 있음, 웅크림, 눕는 동작이 애매하다.
- **분할은 사람(피험자) 기준**으로 한다. 같은 사람이 train과 val/test에 같이 있으면 점수가 부풀려진다.
  - 사람 정보가 없으면 장소나 촬영 회차 기준으로 나누고, 그렇게 했다고 보고한다.
- val과 test에 넘어짐 영상과 정상 영상이 모두 있어야 한다.
- `video_file`은 이 폴더 기준 상대 경로이다. 경로 구분자는 `/`를 쓴다.

## 실행 요령
- 모든 명령은 **이 폴더(train/)에서** 실행한다. 결과 폴더는 상대 경로로 이 폴더 안에 생긴다.
- 환경
  - Python 3.11 conda 환경을 권장한다. 3.13 이상은 패키지 설치가 실패할 수 있다.
  - 셸에서 `conda activate`가 명령 사이에 유지되지 않으면 환경의 python을 전체 경로로 부른다.
  - 학습 전에 `python -c "import torch; print(torch.cuda.is_available())"`로 GPU를 확인한다.
- **03 관절 추출**
  - GPU 프로세스 1개로 돌린다. 8GB GPU에서 2개를 동시에 돌리면 메모리가 부족했던 이력이 있다.
  - 영상이 많으면 출력을 `logs/`에 남기면서 백그라운드로 돌린다.
  - 끊겨도 같은 명령을 다시 실행하면 끝난 영상은 건너뛴다.
- **04 사람 선택과 정답**
  - 영상마다 사람이 1명이면 `--single <이름>`을 붙인다.
  - **멈추고 보고할 조건:** [확인 1] 쓰러진 사람 관절 검출률(학습에 쓰는 영상)이 70% 미만. 카메라 각도나 해상도 문제일 수 있다.
  - `logs/label_check_<이름>/*.png` 몇 장을 직접 열어 확인한다.
    - 정답이 0→1→2로 바뀌는 시점이 실제 장면과 맞는지 본다.
    - 뼈대(초록선)가 사람에 겹치는지 본다.
  - `logs/person_log_<이름>.csv`의 제외 사유(no_person, low_coverage, ambiguous) 개수를 보고한다.
- **05 특징 계산**
  - '몸통 각도 평균'에서 쓰러짐 값이 정상보다 0.2 이상 커야 OK이다.
  - OK가 아니면 관절이나 정답을 의심한다.
- **06 학습**
  - 전이학습 기본값은 `--init runs/Rb_r2_sel/tcnte_seed0/best.pt --lr 1e-4 --hn-weight 3`이다.
  - 데이터가 적을수록 lr은 낮게, 에폭은 짧게 잡는다.
  - 시드 3개 앙상블이 원래 방식이다. seed N은 tcnte_seedN에서 출발한다.
  - `--exp`에는 항상 새 이름을 쓴다.
- **07 평가:** 내 데이터면 `--labels-tag <이름>`을 붙인다.

## 지켜야 할 규칙
- **`runs/Rb_r2_sel/`은 덮어쓰거나 지우지 않는다.** 출발점이자 비교 기준이다.
- 기존 결과도 덮어쓰지 않는다. 새 실험은 새 `--exp` 이름을 쓴다.
- **고르는 것은 val로만 한다.** 에폭, lr, 판정값(th_fall, th_down, window_s, v_gate)이 모두 해당한다.
  - test는 최종을 정한 뒤 한 번만 돌린다. 숫자는 나온 그대로 보고한다.
  - test 결과를 보고 설정을 다시 고르지 않는다.
- 비교 기준을 같이 보고한다. 같은 test에서 **R-b를 그대로 쓴 결과**를 낸다 (`07_evaluate.py --runs runs/Rb_r2_sel/tcnte_seed0 ...`, 또는 3개 앙상블은 `--ensemble`).
  - 전이학습이 실제로 나아졌는지는 이 기준과 비교해야 알 수 있다.
- 영상 데이터, 관절, 시퀀스, 학습 결과는 git에 올리지 않는다. `.gitignore`가 막고 있으니 그대로 둔다.
  - AI Hub 등 외부 공개가 금지된 데이터는 특히 주의한다.
  - push는 사용자가 시킬 때만 한다.

## 보고할 것 (한 번에 정리)
1. 데이터: 분할별 영상 수, 정답 프레임 수(0/1/2/제외), 분할 기준
2. 04 결과: 제외 사유 개수, [확인 1] 검출률, 라벨 그림을 보고 판단한 내용
3. 학습: 명령 그대로, 시드별 최고 val macro-F1과 그 에폭, 걸린 시간
4. 평가: test 결과 (전이학습 모델 대 R-b 그대로), 고른 판정값
5. 코드를 고쳤다면 무엇을 왜 고쳤는지
